# Wiki

This is the project's practical knowledge base for people and agents. A new
teammate should be able to find the right document and complete a task without
relying on undocumented context.

Examples include bootstrapping an environment, running the app, generating code,
running checks, opening the app and taking screenshots, deploying, and diagnosing
common failures. Include prerequisites, exact commands, where to run them,
expected results, and troubleshooting details when relevant.

Keep pages focused and use descriptive filenames. Maintain [index.md](index.md)
as the entry point: add a relative link and a short description for every guide,
and group related guides as the wiki grows. Update instructions when workflows
change, and link to requirements, decisions, and artifacts for supporting context.
