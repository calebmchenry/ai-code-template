# Artifacts

Keep files worth preserving alongside the project's written documentation:
screenshots, mockups, architecture diagrams, recordings, research outputs, and
other supporting material. Any useful file format belongs here.

Use descriptive filenames or topic subdirectories, and link to each artifact
from the relevant requirement, decision, or wiki page with enough context to
explain what it shows. For editable diagrams and designs, keep the source when
available alongside any exported preview.

Avoid committing credentials, private user data, and disposable build output.
