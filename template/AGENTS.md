# Agent guide

Start with the [project README](README.md) and [wiki index](docs/wiki/index.md).
Read the relevant guidance before implementing a task. The
[documentation map](docs/README.md) explains where project knowledge belongs.

- Track work with `wrk`; follow the [issue workflow](docs/wiki/issue-tracking.md).
  Reuse or create a ticket, mark it `in-progress` before implementation, and run
  `wrk validate` before handing off. Change ticket metadata through the CLI.
- Check relevant [requirements](docs/prds/README.md) and
  [decisions](docs/decisions/README.md) before changing behavior or architecture.
- Keep documentation current as you work. Record reusable procedures in the wiki
  and link new pages from its index; keep supporting files in
  [artifacts](docs/artifacts/README.md).

Keep this guide short. Put detailed instructions in the wiki and link them here
only when they are needed frequently.
